# Store categories in statement review (C4)

At base `eb614ceb5be5eb3c11aa59160729bb133eeaaf76`, participants approve statement lines before they count in Budget or Mia. `ParticipantPlan` determines ready lines and questions; `LineApprover` saves explicit answers through the source-review domain and its overlap, ownership, matching, and projection guards. The task brief requires remembered categories to prefill for approval rather than save unattended.

This implementation groups category-only questions by the cleaned store name, up to the existing 100-line request limit. One category selection submits explicit edited answers in a single batch. Participants can expand a group to change individual lines. Guard questions remain individual. Review names use `MerchantNormalizer`; masked original bank descriptions remain available in line details. Category memory reads current approved heads, including the same statement. Saved lines retain their own approved category for timeout retries, regardless of subsequent store memory.

No migration is needed. Existing current approved versions supply memory; superseded or excluded versions do not. No existing transaction is recategorized until a participant saves an answer. No financial policy or persona configuration changes are intended.
